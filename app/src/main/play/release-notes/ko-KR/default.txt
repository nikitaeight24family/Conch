새로운 기능
• 플로팅 창을 새로 만들었습니다. 오래된 턴의 답변 대신 실시간 상태(동작, 경과 시간, 토큰, 실행 중인 에이전트, 대기열)를 보여줍니다. 실제로 작업이 진행 중일 때만 열리고, 실수로 누르기 쉬웠던 정지 버튼은 없앴습니다.
• "+ 새 대화"는 항상 새 대화를 엽니다.
• 상단 표시줄에는 대화의 모델이 나옵니다(서브에이전트 모델이 아님).
• 에이전트 패널: 상태, 모델, 토큰, 도구 사용 횟수, 실행 시간.
• 대기열의 메시지는 턴이 끝나면 반드시 전송됩니다(정지 이후에도).
• 최근 목록에 카드 하나만. 답변이 도착하면 3번 진동합니다.

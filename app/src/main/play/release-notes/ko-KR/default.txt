새로운 기능
• 서버에서 실행 중인 세션을 다시 열면 완전히 라이브로 돌아옵니다 — 정지 버튼, 경과 타이머, 토큰 수, 그리고 응답이 파일에서 바로 그려집니다(턴 도중 앱을 닫았어도).
• 큰 채팅도 즉시 열립니다. 백그라운드 동기화는 데이터를 아낍니다.
• 유휴 채팅에서도 사용량 한도가 정확하게 유지됩니다.
• 더 많은 서버에서 작동(Alpine/BusyBox/BSD/macOS). Windows OpenSSH 서버는 정직하게 표시됩니다.
• 수정: 정지가 턴을 확실히 멈춥니다. 실행 중인 턴으로 보낸 메시지는 중단하지 않고 대기열에서 기다립니다. 오래된 세션의 잘못된 "작업 중" 표시 제거.

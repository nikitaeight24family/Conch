• Stopp ist absolut: der Turn bricht sofort ab — egal ob er auf dem Server läuft, früher von diesem Handy gestartet wurde oder die Verbindung gerade abriss. Ein Stopp ohne Verbindung greift, sobald der Server wieder erreichbar ist. Wartende Nachrichten gehen danach weiterhin raus.
• Behoben: ein Vibrieren, das bis zum Abwürgen der App weiterlief, und eines beim Senden.
• Anmeldung repariert: Senden antwortet immer, der Code wird zuverlässig aus der Zwischenablage übernommen.

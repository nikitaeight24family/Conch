One session, wherever you are.

• Continuing a Codex chat continues it - it no longer starts a fresh, empty one when the session is busy.
• Move a session between phone and server freely: the phone hands it back when it goes idle or you leave the app.
• If a terminal on the server is holding the session, tap the row to take it over.
• The built-in terminal is far faster with long output, scrolls properly, and has a jump-to-newest button.

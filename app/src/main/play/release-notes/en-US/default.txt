• No more phantom duplicates of old sessions. The context-usage probe used to copy a session under a fresh id next to the original for a few seconds; the list picked the copy up as a second session with the same title, then the copy vanished and tapping it opened an empty chat. The copy now lives in a directory the list never reads, and is always removed.
• After /clear or a fork, the previous conversation keeps its row in the list.

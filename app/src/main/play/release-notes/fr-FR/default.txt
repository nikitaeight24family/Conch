• Le téléphone se réveille avec un assistant, pas avec une erreur. Quand le Linux de ce téléphone attend un interrupteur que vous seul pouvez activer, Conch vous guide pas à pas par-dessus ce que vous faisiez ; chaque étape avance dès que le téléphone est prêt. L'app démarre ensuite le Linux.
• Si le téléphone refuse d'ouvrir la page Android, l'assistant le dit et ouvre les Paramètres.
• S'il n'y a pas encore de Linux, il propose de l'installer.

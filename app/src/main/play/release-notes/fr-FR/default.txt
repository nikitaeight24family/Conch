Reprenez une session Claude où que vous soyez - et sortez bien moins votre clé.

• Une session ouverte dans un terminal n'en reçoit plus une seconde à votre insu : le chat dit où elle est tenue, une pression la reprend.
• Commencez sur le portable, continuez sur le téléphone : une session inactive est rendue quand vous rangez le téléphone.
• Les sessions courtes lancées dans un terminal apparaissent sur le téléphone.
• Chat, liste et reconnexion utilisent la clé approuvée par votre serveur.

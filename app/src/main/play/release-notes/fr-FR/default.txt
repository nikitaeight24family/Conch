Nouveautés
• Stop est absolu : le tour s'arrête aussitôt, qu'il tourne sur le serveur, ait été lancé plus tôt par ce téléphone ou que la connexion vienne de tomber. Un Stop appuyé sans connexion s'applique dès que le serveur revient. Les messages en file partent toujours ensuite.
• Corrigé : une vibration qui durait jusqu'à l'arrêt forcé de l'app, et une autre à l'envoi.
• Connexion réparée : le bouton répond toujours, le code est repris du presse-papiers.

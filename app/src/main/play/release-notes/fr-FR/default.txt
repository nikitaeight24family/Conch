Corrigé : « APDU error: 0x6d00 » lors de l'importation depuis une clé NFC nécessitant un code PIN.

• Saisir le code PIN tout en maintenant la clé contre le téléphone provoquait souvent une perte de connexion.
• Le processus est mis à jour : si votre clé nécessite un code PIN, l'application vous demandera de le saisir d'abord, puis de présenter la clé une seconde fois.

• El teléfono se despierta con un asistente, no con un error. Cuando el Linux de este teléfono necesita un interruptor que solo usted puede activar, Conch le guía paso a paso sobre lo que esté haciendo; cada paso avanza solo en cuanto el teléfono está listo. Después la app inicia el Linux y cierra la ventana.
• Si el teléfono no abre la página de Android, el asistente lo dice y abre los Ajustes.
• Si aún no hay Linux en el teléfono, ofrece instalarlo.
